# Video Upload Implementation - Frontend Thumbnail Generation (Option A)

## Overview
Task #15 implementation using **frontend thumbnail generation** instead of ffmpeg. This approach works on any hosting platform and is the industry standard used by WhatsApp, Telegram, and other messaging apps.

## Architecture

### **Flow Diagram**
```
User picks video (FilePicker)
  ↓
Flutter validates locally
  ├─ Duration check (max 10 seconds) using video_player
  ├─ File size check (max 50MB)
  └─ Format check (MP4, MOV, AVI)
  ↓
Flutter generates thumbnail using video_thumbnail package
  ├─ Extract frame at 1 second or 10% duration
  ├─ Size: 640x360px (16:9 aspect ratio)
  └─ Quality: JPEG 85%
  ↓
Upload both video + thumbnail to backend
  ├─ POST /api/attachments/video/upload
  ├─ Multipart form-data: video, thumbnail, metadata
  └─ Progress tracking
  ↓
Backend validates
  ├─ Magic bytes validation (video + thumbnail)
  ├─ Duration validation (max 10s)
  ├─ File size validation (max 50MB)
  └─ Google Vision API moderation (thumbnail)
  ↓
Backend uploads to Firebase Storage
  ├─ Video: videos/{conversationId}/{uuid}.mp4
  └─ Thumbnail: videos/{conversationId}/{uuid}_thumb.jpg
  ↓
Backend creates message in Firestore
  ├─ Video URL
  ├─ Thumbnail URL
  └─ Metadata (duration, dimensions, size)
  ↓
Backend sends to Meta Graph API (for Instagram/Messenger)
  ├─ Sends video URL only
  ├─ Meta downloads video
  ├─ Meta generates their own thumbnail
  └─ Meta optimizes and hosts video
  ↓
User sees
  ├─ Your app: Shows your thumbnail in chat
  └─ Instagram/Messenger: Shows Meta's thumbnail
```

### **1. Video Upload Service**
**File**: `lib/services/attachments_api_service.dart`

**Method to Add**:
```dart
Future<VideoUploadResult> uploadVideo({
  required File videoFile,
  required String conversationId,
  Function(double)? onProgress,
}) async {
  // Step 1: Validate video locally
  await _validateVideo(videoFile);
  
  // Step 2: Get video duration and dimensions
  final controller = VideoPlayerController.file(videoFile);
  await controller.initialize();
  final duration = controller.value.duration.inMilliseconds / 1000.0;
  final width = controller.value.size.width.toInt();
  final height = controller.value.size.height.toInt();
  controller.dispose();
  
  // Step 3: Generate thumbnail
  final thumbnailData = await VideoThumbnail.thumbnailData(
    video: videoFile.path,
    imageFormat: ImageFormat.JPEG,
    maxWidth: 640,  // 16:9 aspect ratio
    maxHeight: 360,
    quality: 85,
  );
  
  // Step 4: Create multipart request
  final request = http.MultipartRequest(
    'POST',
    Uri.parse('$baseUrl/attachments/video/upload'),
  );
  
  // Add files
  request.files.add(await http.MultipartFile.fromPath('video', videoFile.path));
  request.files.add(http.MultipartFile.fromBytes(
    'thumbnail',
    thumbnailData!,
    filename: 'thumbnail.jpg',
  ));
  
  // Add metadata
  request.fields['conversationId'] = conversationId;
  request.fields['duration'] = duration.toString();
  request.fields['width'] = width.toString();
  request.fields['height'] = height.toString();
  
  // Step 5: Send with progress tracking
  final response = await request.send();
  final responseData = await response.stream.bytesToString();
  return VideoUploadResult.fromJson(jsonDecode(responseData));
}

Future<void> _validateVideo(File file) async {
  // File size check
  if (file.lengthSync() > 50 * 1024 * 1024) {
    throw Exception('Video must be less than 50MB');
  }
  
  // Duration check
  final controller = VideoPlayerController.file(file);
  await controller.initialize();
  final duration = controller.value.duration.inSeconds;
  controller.dispose();
  
  if (duration > 10) {
    throw Exception('Video must be less than 10 seconds');
  }
}
```

## Meta (Facebook/Instagram) Integration

### **Sending Videos to Meta**

When sending video messages to Instagram/Messenger customers:

```typescript
// backend/src/messages/messages.service.ts

async sendVideoMessage(conversationId: string, videoUrl: string) {
  const conversation = await this.getConversation(conversationId);
  
  // Send to Meta Graph API
  const response = await fetch(
    `https://graph.facebook.com/v18.0/me/messages?access_token=${accessToken}`,
    {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        recipient: { id: conversation.externalUserId },
        message: {
          attachment: {
            type: 'video',
            payload: {
              url: videoUrl,  // Your Firebase Storage URL
              is_reusable: true
            }
          }
        }
      })
    }
  );
  
  // Meta will:
  // 1. Download the video from your URL
  // 2. Generate their own thumbnail
  // 3. Transcode/optimize the video
  // 4. Host it on Meta's CDN
  // 5. Send to Instagram/Messenger user
}
```

**Important**: 
- ✅ Meta accepts video URLs (not files)
- ✅ Meta generates their own thumbnails
- ✅ You don't send your thumbnail to Meta
- ✅ Max 4GB, max 240 minutes (we enforce 50MB, 10s)

## Benefits of This Approach

### **vs. Server-Side FFmpeg**:
| Feature | Frontend Thumbnail | Server FFmpeg |
|---------|-------------------|---------------|
| Server dependencies | ✅ None | ❌ Requires ffmpeg binary |
| Hosting compatibility | ✅ Works anywhere | ❌ Need Docker/custom runtime |
| Processing speed | ✅ Instant (parallel) | ❌ Slower (sequential) |
| Server CPU usage | ✅ Zero | ❌ High |
| Implementation | ✅ Simple | ❌ Complex |
| Cost | ✅ Free | ❌ Higher compute costs |

- ✅ Telegram: Generates thumbnails client-side
- ✅ iMessage: Generates thumbnails client-side
- ✅ Signal: Generates thumbnails client-side
